# Flutter Cake Shop App

แอปตัวอย่างรายวิชา Mobile App Development พัฒนาด้วย Flutter

---

## Features

- Splash Screen (ธีมร้านเค้ก)
- หน้าแสดงรายการร้านเค้ก (`CakeShopListUi`) + Carousel
- หน้ารายละเอียดร้าน (`CakeShopDetailUi`)
- แผนที่จริงจากพิกัดร้านด้วย `flutter_map` + `latlong2`
